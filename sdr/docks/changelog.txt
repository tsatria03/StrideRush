New in 2.0.
Fixed a bug where dying in a practice run left you still wearing your old shield, as well as giving you a fresh one.
Made it so the arrow keys now jump, crouch and switch lanes again, tab and shift plus tab move through your inventory, enter uses an item, and page up, page down, home and end change the music and ambience volume, alongside the letter and F keys, which all still work as before.
New in 1.9.
Made it so barriers now come about twice as often as each other kind of obstacle, since many of them pass in another lane.
Made it so life capsules, steel shields and health potions now come much less often, and less often still on each harder difficulty, so you can no longer survive forever by taking every hit, leaving more room for obstacles.
Made it so the game no longer checks for updates when it starts unless you toggle that setting in the settings menu's general tab, which is now unchecked to start with.
Fixed a bug where the learn sounds menu counted every version and layer of a sound as a separate sound, so countdowns said it had 85 sounds when it holds 9, and it now says 9 individual sounds, 85 in total.
Removed the F7 and F8 keys for the heartbeat volume, which is now changed only with its slider in the settings menu's game tab.
Added a footsteps volume slider to the settings menu's game tab, which turns down only your footsteps, not your landings or falls.
Made it so control plus tab and control plus shift plus tab now move to the next or previous tab in the settings menu, from anywhere in it.
Added practice locks, so each practice obstacle opens once you've got past 5 of the one before it, and endless run opens once you've jumped over 5 hazards in a practice run, while anyone who has already played an endless run has everything open.
Made it so quitting or restarting a practice run now just asks if you're sure, without warning that you'll lose your session's progress.
Made it so every run now starts with your fist drawn, instead of the bat.
New in 1.8.
Made it so the key binder now takes combinations such as shift plus tab, binds either side of shift, control or alt when you hold both, warns you when a key already belongs to another action and offers to replace it, only shows the trigger menu when you ask to change it, and keeps keyboard.ini in its short form when it saves.
Made it so add binding in the rebind list now adds a key to the action you have selected, instead of asking you to choose the action again from another list.
Made it so each action now has a single key by default, such as W to jump, Q and E to switch lanes, A and D for your hands and F3 to F8 for the volumes, leaving the arrows, tab, enter, home, end, page up and page down free for you to bind in the settings menu.
Fixed a bug where drawing one weapon after another played both draw sounds over each other, instead of the new one cutting off the last.
Made it so practice runs now offer fake doors, real doors and mixed doors, instead of only a mix of real and fake doors.
Made it so dying in a practice run, from a hit on your last life or a fall into a hazard, now stops the run like a real death, then lets you try again from just past what caught you with your health, life and shield back, and practice runs now start with 1 life and 1 steel shield instead of 2.
Made it so each difficulty level now changes how much damage you take, how tough walls and fake doors are, and how fast the belt can go, from 60 percent of the damage and toughness and a top speed of 5 steps a second on easy, up to the full amount and 20 steps a second on chaos.
Removed a bunch of ambiences and platforms that were no longer needed in the game.
Made it so resetting your settings now restarts the game, so every setting starts fresh.
Made it so the menu music, music and ambience volumes now start at 80 percent instead of full volume, including after you reset your settings.
New in 1.7.
Made it so the sound device menu now tells you which device is active.
Made it so the setting to check for updates when the game starts is now in the general tab of the settings menu, instead of the game tab.
Made it so the practice run's speeds are now given in steps a second instead of milliseconds.
Added a getting started section near the top of the readme, which walks you through starting your first run and the few keys you need to stay alive, and the keyboard commands now come right after it instead of at the end, while the rest of the readme stays as the full reference.
Added a heartbeat that speeds up as you run faster, from 5 beats per minute at the start up to 155, which B now tells you, and which you can turn up or down with shift plus home and end or F7 and F8, or from a new game heartbeat volume slider in the settings menu.
Made it so the pause menu now opens on resume run and remembers your place when you back out of anything inside it.
Made it so pressing escape or P during a run now pauses every sound but the ambience, so the game is never silent while you decide.
Made it so Alt plus F4 now does nothing during a run, instead of closing the game.
Added volume sliders to the settings menu, with game ambience and game music volume in the game tab and menu music and master game volume in the sound tab, and the game's music and ambience can now go much quieter than before.
Added settings in the game tab to turn off the session results after you die, and the copy and export options in the menu that follows.
New in 1.6.
Made it so dying in an endless run now shows your results for the run, starting with your death outcome, followed by a menu where you can copy or export them, replay the run, or return to the game menu, instead of only asking whether to replay.
Added view, copy and export session results options in the pause menu during an endless run, so you can check your stats for the run so far, and restart run now comes right after resume run.
Added options in the game menu to clear, copy or export all of your game progress, both your statistics and your achievements, where clearing never changes which difficulties you've unlocked.
Added game achievements in the game menu, over 80 of them across single runs and all your runs, which are announced the moment you earn one and stay earned for good, and achievement statistics in the statistics menu now show your progress on each one.
Added options to clear, copy or export your game statistics, where clearing never changes which difficulties you've unlocked, and exporting saves them to a text file.
Added game statistics in the game menu, where you can look through your last endless run and your totals across every run, from steps and top speed to every obstacle you've got past or been hit by, every item you've picked up and every shot you've fired.
Made it so C now tells you your speed in steps a second instead of milliseconds per step.
Made it so Z now tells you how far you've run in steps instead of tiles.
Made it so the I key now moves to the previous item in your inventory and the O key to the next one, instead of the shift plus I and I keys.
Added music and ambience to every run, where the music shuffles through all its tracks one after another, and the ambience changes to a new place every 1 to 2 minutes, fading from one into the next, with F3 and F4 now also changing the music volume and F5 and F6 the ambience volume.
New in 1.5.
Made it so the laser is now replaced by a sword, on 8, with new sounds for most of the other weapons.
Added difficulty locks, so each level after easy opens once you've finished 5 runs on the level below it, and a run only counts if you opened a real door and got through it before you died.
Added five difficulty levels for the endless run, from easy to chaos, which start you at different speeds, give you more or less room between obstacles, and bring in new kinds of obstacles and items as you speed up, while chaos throws everything at you from the start.
Added a choice of game modes when you play the game, where endless run plays the game as before, and practice run lets you practice one kind of obstacle at a speed you choose for as long as you like, without losing or counting toward your progress.
Made it so the speech buffers now sort what the game says into doors, items, powerups, status, weapons and misc, each showing up only once something has been spoken into it.
Added a change game version option in the main menu, where you can type an older version number so the updater offers you the latest version again, until you close the game.
Added an auto updater, which checks for a new version when the game starts and from a new check for updates option in the main menu, and downloads the installer or the portable version for you, and the settings menu now lets you turn off the check at startup.
Added a learn sounds menu in the game menu, where you can play the sounds of items, obstacles and weapons and every obstacle's countdown, and the settings menu now lets you choose whether those sounds loop and whether the menu tells you when a sound has several versions.
Added a test speakers option in the main menu, which plays a sound so you can check your speakers or headphones before you play.
Made it so walls are now easier to break at high speeds, so your guns can get through them in time, while fake doors are now much tougher than walls.
New in 1.4.
Made it so the belt now carries you forward instead of to the right, so obstacles come at you from straight ahead and fall behind you once passed, items now sit in one of the three lanes and can only be picked up, broken or hit from that lane, and the settings menu now lets you turn off HRTF and the lower pitch of things behind you.
Added barriers, such as cars, boulders and firewalls, which fill a single lane, sometimes two side by side with one lane always left open, and which you can only get past by switching lanes, or they take 80 of your health.
Added lanes, so the belt now has a left, middle and right lane that you switch between with the left and right arrows or Q and E, and L tells you which lane you're in.
Made it so steel shields now take 400 damage before they break, twice as much as your own health.
Made it so force fields now take 30 of your health, projectiles 40, walls 50, mines 60 and doors 70, so the harder obstacles hurt more.
Made it so life capsules now give 1 or 2 lives, up to a limit of 20 lives, and stay in your inventory for later when you're already at the limit.
Made it so doors now have a warning countdown like every trap, which stops once you open a real door or break a fake one.
Added animals, birds and dogs, which call out ahead of you and run into you for 10 of your health unless you clap by pressing both hand keys together during their countdown to scare them away, and your hands now make a sound when there's nothing for them to grab.
Added health potions, which turn up more often than life capsules, and which you pick up with either hand and use with U to heal 5 to 10 percent of your health.
Made it so life potions are now called life capsules, with new sounds for finding, picking up, breaking and using them.
New in 1.3.
Made it so your settings and volumes are now remembered between launches, leaving a run now fades its sounds out instead of cutting them off, and space now also closes a dlg message.
Added a settings menu in the main menu, with general, game, keyboard, menu, sound and speech tabs, where you can rebind your keys, pick your sound device, set up and preview your voice, and choose whether escape asks before quitting a run, and F2 opens its game, menu and speech tabs during a run.
Added a key bindings screen, which you open with F1 during a run or from the settings menu, and which lists every action and the keys it's on.
Made it so melee weapons can now swing at most every fifth of a second, and the pistol fire every tenth of a second, so you can hear the weapon powerups change them.
Added powerups, which you collect by running over them on the ground or jumping into them in the air, and which give you a good or bad effect for 15 seconds, such as moving faster or slower, jumping longer or shorter, or taking less or more damage.
Made it so P is now the only key for the pause menu, and pressing escape during a run asks whether you want to quit it, with the run stopped while you decide.
Added a prompt after you die that asks whether you want to replay the current run.
Made it so the pause menu now lets you resume, restart or quit the run, and asks you first before you restart or quit.
Added a game menu, where you start a run, and a restart game option in the main menu that closes and reopens the game.
Added a documentation menu in the main menu, where you can read the changelog, credits, readme and todo list.
New in 1.2.
Made it so the H key now tells you your health and lives, and you no longer hear your own landing when a force field throws you or a teleporter moves you.
Added player health, so you now have 200 health that obstacles wear down instead of taking your lives straight away, and you only lose a life when your health runs out.
Made it so you can no longer use your inventory while a door is carrying you.
Added player teleporters, which you pick up with either hand and use with U to be thrown a random 2 to 5 seconds forward or back along the belt, sometimes right in front of danger.
Added life potions, which you pick up with either hand and drink with U for 1 extra life.
Made it so the lives key is now H instead of L, and the new M key tells you how strong your shield is.
Added steel shields, which you pick up with either hand and wear with U, and which take the damage from spikes, mines, force fields, projectiles, walls and doors in place of your lives until they break.
Made it so a fake door now sounds jammed when you try to open it with your hands, or use a key on it, so you can tell it won't open.
Made it so real doors are now locked, so you press U with a key from your inventory to unlock one from up to 2 seconds away, then open it with either hand.
Added keys, which turn up once before each real door in a choice of colors, and which you pick up with either hand, but which break if you run onto them, land on them or hit them with a weapon.
New in 1.1.
Made it so your weapons now break ammo packs, so a shot or swing at a pack in your way destroys it, and an ammo pack now gives 5 to 10 rounds to the gun you're holding, instead of 50 to both.
Made it so guns now fire bullets that fly ahead of you with their own sound, so a shot only lands if its target is within reach, and each gun now starts with 50 rounds in reserve, up to 200.
Added fake doors, which sound slightly higher or lower than a real door, can't be opened and have to be broken with your weapons, and cost 3 lives if you crash into them.
Added real doors, which mark each new speed section and carry you through when you open them with either hand, but cost 3 lives if you crash into them.
Added walls, which you have to break with your weapons before you reach them, which get tougher the faster you run, and which cost 1 life if you crash into one.
Made it so a force field's countdown now stops as soon as you switch it off.
Added over a hundred new ground surfaces to run on, such as dirt, grass, gravel, leaves, sand and stone.
Made it so you can now crouch again half a second after standing up, instead of a full second.
Made it so the ground now changes to a new surface every 10 to 20 seconds at any speed, instead of after a set distance, which made it change very rarely at the start of a run.
Made it so every trap now plays its full five-step warning countdown at any speed, instead of the countdown getting shorter as you speed up.
New in 1.0.
Added ammo packs, which you pick up with either hand as you reach them and later open from your new inventory to refill both guns' reserves, but which break if you run or land on top of them.
Added ten weapons on the number keys, from the bat up to the machine gun and pistol, which you swing or fire with the space bar, with separate ammo for each gun and reloading at any time.
Added projectiles, including missiles, cars, boulders and firewalls, which fly toward you twice as fast as you run and cost 1 life unless you crouch under them.
Added left and right hand keys, either of which you can use to switch off force fields.
Added force fields, which hit you even if you jump or crouch, cost 1 life, and throw you 5 steps forward unless you switch them off with either hand during their countdown.
Added a warning countdown before spikes and mines, the same way hazards have one, with different sounds for each kind of obstacle so you can tell which one is coming.
Added mines, which light up and start ticking as you get close, cost 2 lives if you step on one, and fade out behind you once you jump over them.
Added spikes, which swing back and forth and cost 1 life if they hit you.
Added ledges in front of every hazard, with a step-by-step countdown that tells you when the hazard is coming.
Added hazards, including pits, chasms, fire, lava, water, quicksand and electricity, which end your run if you fall into one.
Added death sounds for each kind of obstacle, after which you return to the main menu.
Added a lives system. You start each run with 1 life, and the run ends when your last life is gone.
Added crouching, which you hold to stay down, with your footsteps going quiet while you're crouched.
Added jumping, with a landing sound for the ground you come down on.
Added footstep sounds on every step, with the ground changing between carpet, cement, concrete and marble as you run.
Added speech buffers, so you can review, copy and export everything the game has spoken during a run.
Added a pause menu, where you can resume the game or quit back to the main menu.
Added keys to change the music and ambience volume during a run.
Added keys to hear your lives, distance, speed and running time.
Added endless runs that start at 500 milliseconds per step and speed up by 10 milliseconds every 10 seconds, up to a top speed of 50 milliseconds per step.
