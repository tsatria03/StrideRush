In anything committed (memory, docs, changelog, code comments), refer to games the dev didn't make generically, such as "an external reference game". The dev's own games can be named.

**Why:** the dev is fine crediting their own work but doesn't want other creators' games named in their files.

**How to apply:** keep the borrowed design, scrub the source name. Chat replies aren't committed, so this applies to files only.
