  type: feedback

Only propose a preset system, template, or externalized type folder for an object when there's a real pain point (too many fields to type by hand) or expressed demand, not because it's technically possible or symmetrical.

**Why:** in SimpleFighter the dev swept every builder entity and found only NPCs (30+ fields) and effects (players wanted presets) justified it. Anything else is maintenance with no payoff.

**How to apply:** when tempted to suggest one for a Stride Rush obstacle or object, check for the pain point first. Related: [[feedback_confirm_before_implementing]].
