The dev asked for alphabetical order in several places on 2026-11-05 (the debug spawn menu, the learn sounds menu and its lists, natural order for numbered names, the speech buffers), then said, while planning the difficulty menu: "I'll let you know if a menu ever needs alphabetical sorting, but this menu will not need it."

**Why:** some menus have a natural order of their own (a difficulty scale easy to chaos, Yes then No, the main menu's layout), where alphabetical would read as nonsense.

**How to apply:** keep the menus already made alphabetical that way, and when adding to them keep them sorted. For a new menu, use its natural order and don't propose alphabetical unless the dev asks. When names with numbers are sorted, use natural order (bird, bird2 ... bird10), [[project_learn_sounds_plan]].
