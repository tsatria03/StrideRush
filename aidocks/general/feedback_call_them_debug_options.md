The source-only menus shown before a run (speed, spawn, and "end the run when out of lives?"; SCRIPT_COMPILED hides them in releases) are called the debug options (dev, 2026-11-03: "the debug options, which by the way is what we should call it to make it clearer"). Older memories and plans call them the "testing menus" or "testing spawn menu"; that means the same thing.

**Why:** "testing" was easy to confuse with the dev's test steps for each build section, and with features that also exist in releases (such as the play-again prompt).

**How to apply:** say "debug options" in chat, test steps, code comments, menu intro text and new memories. Related: [[project_menus_plan]], [[feedback_test_steps_one_at_a_time]].
