The two references (read only, 2026-11-03):
- Both: a "documentation menu" main-menu item opening a docksmenu() with changelog, credits, readme, todo_list and back; picking one fades the menu music and calls dockread(), which opens an audio form window "Viewing <file>" with a read-only multiline input box holding the whole file and a close button; a missing file shows an alert "Could not find <file>".
- ToyMania (menus/menu.nvgt, functions/extrafuncts.nvgt): docksmenu() runs once, and every exit (escape, back, close) calls mainmenu() or docksmenu() again, so menus stack recursively; a missing file alerts and then carries on to open it anyway; an optional "loading" speech; a longer intro text.
- SimpleFighter (menus/menu.nvgt, sf.nvgt): docksmenu() is a while loop that returns on escape or back, and dockread() simply returns on close or a missing file, so nothing stacks; intro "Documentation menu"; a preferences screen can hide the item from the main menu (hidedocks).
- Verdict (Claude): SimpleFighter's is better, the same features without the recursion and the missing-file bug, and it matches Stride Rush's loop-based menus.
