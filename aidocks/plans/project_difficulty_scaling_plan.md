Background:
- The dev (2026-11-09): "to make the game a bit easier, you could lower the damage recieved by obsticals by like 20 percent per difficulty so than by chaos, you get the full damage. The same applies, but for the max run speed cap, witch is currently 50ms for all diff modes." With examples for both: "easy=20, medium=40, hard=60, insain=80, chaos=100".
- Now: every obstacle does its full damage on every level (animals 10, spikes 20, force fields 30, projectiles 40, walls 50, mines 60, doors 70, barriers 80, through take_damage() in lives.nvgt; hazards end the run outright), and every level speeds up to min_step_time 50 ms (20 steps a second). The five levels (difficulty.nvgt's difficulty_names) start at 500, 450, 400, 350 and 300 ms; obstacles and items join at set speeds (projectiles 450 ms ... barriers and powerups 200 ms).
