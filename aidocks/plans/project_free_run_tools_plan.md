Background (dev, 2026-11-14): "I have 2 more suggestions, but they need debug code lookups and one plan for both. Add options to give/take player related stats. Example, health, shield strength, lives. These will appear in each modify menu. In there, you have something like, give health, take health. Add options to modify footstep/lifecard behavior. Similar to the menu prompts in the debug menus."

What the code has now (lookups, 2026-11-14):
- Free run's modify player health, modify player lives and modify shield strength (freerun.nvgt: free_set_health(), free_set_lives(), free_set_shield()) each go straight to a number box (1 to 1000) that sets the full amount and fills it: free_health, free_lives, free_shield_full. Health and lives show while running; shield strength only while a shield is worn.
- The debug footsteps question (menus/menu.nvgt, choose_footsteps()): "Do you want to hear your footsteps while running?" Yes, No; it sets footsteps_on (surface.nvgt), which silences every footstep (landings still play). Source only.
- The debug lives question (choose_lives_can_end()): "Do you want the run to end when you run out of lives?" Yes, No; it sets lives_can_end (lives.nvgt) through start_run(). With No, lives stop at 1 and health just refills on the last life (take_blow()), while a hazard or floor breaker still ends the run and restarts it (restart_run_requested, endrun.nvgt). A free run always starts with Yes.
- Free run's death mode already has normal deaths and practice deaths (practice_deaths()), which overlaps the lives question: practice deaths set you down past what caught you with your lives back.

Proposed sections (to settle through the Q&A):
1. Give and take: each of modify player health, modify player lives and modify shield strength opens a small menu instead of the number box, with give, take, (and set, if kept), and back.
2. Footsteps and lives running out: new console choices modelled on the debug questions.
3. Docks: changelog entries under New in 2.3, the readme's Free runs section, the version history, CLAUDE.md, this plan COMPLETE.
