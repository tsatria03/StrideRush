Status: recorded 2026-11-01 at the dev's request. Nothing built. The dev said "do not build any nvgt code" yet, so each section waits for its own go-ahead ([[feedback_confirm_before_implementing]], [[feedback_describe_dont_show_code]]).

Goal: the game launches, speaks a main menu and exits cleanly. No gameplay, settings, saves, keybinds or updater.

Section 1: launcher (Python, not NVGT)
- sr/sr.py, adapted from SimpleFighter's sf/sf.py.
  - Runs C:\nvgt\nvgt.exe ../src/sr.nvgt with cwd sr/ under CREATE_NO_WINDOW.
  - Watches 5 seconds for an early exit and writes compile errors to sr/errors.txt.
  - sync_version() mirrors build/version.txt into src/includes/version.nvgt.
  - Renames needed: SimpleFighter to Stride Rush in messages, the temp-log prefix, and the script path.
- .gitignore: add sr/errors.txt. Keep src/includes/version.nvgt tracked (decision 4).

Section 2: entry and include tree
- src/sr.nvgt. It holds:
  - preglobals(): a screen reader and sound system check, with alert() fatals.
  - main(), in this order: HRTF and pitch limits (no keyhook, see decision 2), initialize_sound_pools(), show_window("Stride Rush, version "+version), the single-instance block, then loop on mainmenu().
- src/includes/includes.nvgt: version.nvgt plus glob includes of main/deps, main/functions, main/globals and main/menus. Leave main/parsers out until it has a file, since there are no map files ([[project_tech_decisions]]).
- src/includes/version.nvgt: generated by the launcher, never hand-edited ([[feedback_update_build_version_txt]]).

Section 3: shims the copied deps need
The deps are SimpleFighter copies and reference SimpleFighter globals and functions that Stride Rush must supply or trim:
- functions/packfuncts.nvgt: the trimmed SimpleFighter glob layer. Keep find_sound_in_disk(), get_pack_sound() and get_pack_sound_folders(), with the prefix "sounds/" (no pack name, no decompiled/). Drop all .spack pack-file code (find_sound_in_pack, the caches, the folder index), the map and builder packs, and get_map_sound().
- globals/dec.nvgt:
  - menutype ("default"), plus the menu prefs setupmenu reads: first_letter, side_scrolling and speak_menu_position.
  - The temp sound_pool that dlg.nvgt plays through, and the form_menu m instance setupmenu configures (check whether form_menu.nvgt already declares m).
  - The single-instance object.
- globals/decpool.nvgt: initialize_sound_pools() with an all_pools list, following SimpleFighter ([[project_audio_model]]).
- dlg.nvgt edits:
  - Remove the story-zone stztype parameter and its get_map_sound calls.
  - Repoint the error sound to Stride Rush's menu folder.
- setupmenu.nvgt edit: repoint the main/menus/<menutype> paths to ui/menus/<menutype> (ToyMania tree, [[project_sound_layout]]).
- form_menu.nvgt calls writepreffs() when the menu music volume changes. Until preferences exist, supply a minimal writepreffs() or no-op it; decide when building.

Section 4: main menu
- menus/menu.nvgt mainmenu() on form_menu via setupmenu(true):
  - Start game: a placeholder that speaks one sentence ([[feedback_one_sentence_game_messages]]).
  - Exit: quits right away.
  - Escape also quits right away, with no confirm (decision 3). Since it closes the game rather than backing out of a menu, it doesn't speak "canceled".
  - Any later confirm uses Yes/No ([[feedback_yes_no_menu_labels]]), and later submenus still speak "canceled" on Escape ([[feedback_menus_say_canceled]]).
- No sound files exist yet. get_pack_sound returns "" for missing clips, so the menu runs silently until sounds are added.

Open decisions (ask one at a time when building):
1. Sound root: SETTLED 2026-11-01, flat. No top-level sound packs; sr/sounds/ is the root. The folder is misc/player (lowercased by the dev).
2. Keyhook: SETTLED 2026-11-01, none. The dev doesn't want the JAWS keyhook in this game. Leaving keyhook.nvgt out of deps/ was deliberate. No install_keyhook() call, no kh keyhook global.
3. Main menu Escape: SETTLED 2026-11-01. It exits the game right away, with no Yes/No confirm.
4. Generated files: SETTLED 2026-11-01. Commit src/includes/version.nvgt, like SimpleFighter and ToyMania, so a fresh clone compiles without running the launcher first. Gitignore sr/errors.txt so a failed launch's report can't be swept in by tools.py's git add -A. The .gitignore line lands with Section 1.

All open decisions are settled; the plan is ready to build on the dev's go-ahead.

Out of scope: gameplay ([[project_game_design]]), settings, savedata, key_config and keyboard.ini, scoring and difficulty ([[reference_toymania_scoring_difficulty]]), the updater, and the docs reader.

**How to apply:** build one section per go-ahead. Mark sections BUILT here as they land, and flag a commit break point between them ([[feedback_stage_commits_before_big_changes]]).
