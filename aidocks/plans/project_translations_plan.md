# Translations plan

The todo item "Add game translations for other languages." Discussion opened 2026-11-19 at 2.6, 6 of 10.

## Findings

- The engine's include translator.nvgt (misc/Legacy-NVGT/release/include) loads key=value files, has a fallback language, {0} {1} placeholders, and wraps missing keys in [ ] (set_missing_markers() can turn that off). Its parser splits on the first "=", trims whitespace, skips lines starting with # or ;, and treats [name] lines as sections that prefix keys.
- The engine has get_preferred_locales() (SDL), returning strings such as "es-MX".
- Text in the game, roughly: 430 distinct fixed sentences in src, about 150 strings built from pieces (covered by * wildcard lines, no code rewriting), achievements.ini's 86 achievements, the docks, and names built from sound folders and dock file names. Sounds need no translation.
- deps/speech.nvgt's speak() has a text processing callback; form.nvgt speaks through the global speak(); first letter navigation searches stored item text. The General tab is main menu only (F2 mid-run has Game, Menu, Speech), so the language changes only from the main menu. Exports are built by all_progress_text() (achievements_menu), session_results_text() (results_menu) and all_stats_text() (stats_menu). The installer puts the game in Program Files (not writable at run time); APPDATA_DIR is %APPDATA%/tsatria03/StrideRush/.

## Settled design

- Translate at the speech layer: one hook in speak() and speak_buffer() (before it logs), menu items translated in form.nvgt's add_list_item() (so letter navigation and sorting use translated names), and copies and exports translated line by line as they're built. No wrapping of strings in code.
- Our own translator in src (not the engine's translator.nvgt): an exact-line dictionary first, then * wildcard lines in file order, matched against the whole sentence, $1, $2 placing the values.
- .lng format: English=Translated, split at the first =, no quotes or sections, // comments (headings by source), blank lines ignored, UTF-8.
- Files: sdr/data/lang/template.lng (the script's, rewritten in full each run, English=English in code order under // headings, never listed); english.lng (a real language, seeded from the template, then kept by hand). Only English ships for now. Player languages in APPDATA_DIR/lang/*.lng, read first, replacing a shipped file of the same name. A .lng with no lines is skipped.
- Setting: "Language", the General tab's first control, fallback first (the default: no file, the code's English), then languages sorted; applied on save; saved in settings.srf.
- Missing log: a General tab checkbox "Log untranslated lines", off by default, only with a language chosen; APPDATA_DIR/lang/<language>.txt, one per language, each line once, as English=English, across sessions.
- Template script (Python, build/): scans src for spoken strings (fixed sentences as exact lines, text + value + text as * lines; strings built across functions or in loops listed for hand-written patterns), achievements.ini, dock names from docks/lang/english, and names built from sound folders; reports each .lng's missing and stale lines; never writes a language file.
- Data: sdr/data/config/main/keyboard.ini, joystick.ini; sdr/data/config/game/achievements.ini.
- Docks: sdr/docks/lang/<language>/game and main. Documentation menu: languages (from the folders, skipped while english is the only one, focused on the game language, english under fallback), then game or main, then documents. A new main document, translations.txt; the readme untouched.
- Changelog: a new entry on top (7 of 10): "Added game translations, with a language setting in the general tab, so the game and its documents can be read in any language that has a language file, and players can write their own, as the new translations document explains." And 2.6's data entry reworded in place: "Made it so the data folder is now split into a config folder, holding the achievements in its game folder and your key and joystick settings in its main folder, and a lang folder for the game's languages."
