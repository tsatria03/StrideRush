What exists already:
- Settled in [[project_controls_plan]] (2026-11-01): F1 during a run opens the view-key-bindings screen, the same one as the settings Keyboard tab's "View current keyboard bindings", pausing the run while open. F2 opens settings, SimpleFighter-style tabs, no Alt-letter shortcuts; mid-run only the Game, Menu and Speech tabs show (General, Keyboard and Sound hidden, like SimpleFighter's settingsmenu(true)); keys are never rebound mid-run. keyboard.ini [screens] already binds view_bindings (F1) and settings (F2), read by nothing.
- deps/savedata.nvgt: Mason's savedata class (by Ultrocity Audio, with bools added): savedata(filename, key), load(), save(), add(name, value) for bool, double, float, int, int64 and string, and read_bool/read_double/read_int/read_string. It serializes a dictionary, encrypted with string_encrypt when a key is given; a missing file loads as empty.
- functions/savefuncts.nvgt: only an empty writepreffs(), which form_menu calls when the menu music volume changes.
- Volumes: Home/End (ambience) and Page Up/Page Down (music) move by volume_change 1 dB from 0 down to min_volume; they reset every launch.
- SimpleFighter (read only): settings live in "savedata st(DIRECTORY_APPDATA + "tsatria03/SimpleFighter/preffs/settings.spf", <long key>)" in globals/dec.nvgt, read by readpreffs() and written by writepreffs() in functions/savefuncts.nvgt. settingsmenu(bool ingame) in menus/menu.nvgt is one audio_form "preferences" window with a "Category" tab panel (General, Game, Keyboard, Menu, Sound, Speech), checkboxes and buttons assigned to tabs, save settings and cancel buttons, rebuilt in an outer loop after any sub-dialog. Its Keyboard tab has "Rebind keyboard controls" (a list of action: keys with add, edit and remove) and "View current keyboard bindings".
